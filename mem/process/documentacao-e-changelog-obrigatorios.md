Três obrigações permanentes do projeto (reboot em diante):

1. **Documentação tripla sempre**: para cada feature/módulo, produzir (a) documento técnico, (b) documento operacional (como operar/manter), (c) manual de uso detalhado para leigos. Nenhuma entrega está completa sem os três.
2. **Planos no repositório**: todo plano aprovado fica registrado no repositório como histórico de ações (docs/), nunca apenas no chat.
3. **Changelog sempre alimentado**: manter um changelog contínuo atualizado a cada mudança entregue.

**Why:** Pedido explícito do Diogo em 02/09/2026 como padrão do reboot — rastreabilidade total e material de apoio para um ICP não-técnico.
**How to apply:** Toda tarefa termina com docs atualizados + entrada de changelog; toda fase começa com plano registrado em arquivo.
